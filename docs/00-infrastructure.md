**Оценка:** ≈2–3 ч

**Цель:** сервер доступен по HTTPS, все внешние аккаунты заведены.

## Зависимости

- Сервер (VPS или хоумлаб) с публичным IP и SSH-доступом.
- Аккаунт Telegram, аккаунт Google.

### HTTPS

Схема: Caddy MemeQuiz публикует только порт 443 и получает сертификат через TLS-ALPN-01 challenge, которому порт 80 не нужен. Порт 80 остаётся за nginx Pulse.

- [x] Создать на сервере каталог `/opt/memequiz`.
- [x] `Caddyfile`: глобально `auto_https disable_redirects`; сайт `https://memequiz.139-100-225-182.sslip.io` с `respond "ok"` и `tls { issuer acme { disable_http_challenge } }`.
- [x] `docker-compose.yml`: сервис `caddy` (образ `caddy:2`), порты `443:443` и `443:443/udp`, volume для `/data` и `/config`, чтобы сертификаты не терялись при перезапуске.
- [x] В логах Caddy есть `certificate obtained successfully`.
- [x] Открыть `https://memequiz.139-100-225-182.sslip.io` и убедиться, что сертификат валиден и страница отвечает `ok`.
- [x] Проверить, что Pulse по `http://139.100.225.182` работает как раньше.

## Риски / заметки

- `http://memequiz.139-100-225-182.sslip.io` (без https) попадает в nginx Pulse и показывает Pulse. Telegram и ссылки всегда используют https, так что это некритично. При желании позже можно добавить в nginx Pulse `server` с этим именем и редиректом на https.
- Если Pulse когда-нибудь займёт 443, нужно будет объединить прокси: один из них станет фронтовым.

- Let's Encrypt ограничивает количество выпусков сертификатов. При экспериментах не удаляйте volume `/data` у Caddy.
- У sslip.io и DuckDNS тоже бывают лимиты и простои. Для «боевого» запуска можно позже купить свой домен.
- Не теряйте JSON-ключ: Google не даёт скачать его повторно, придётся создавать новый.
