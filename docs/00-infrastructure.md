### HTTPS

Схема: Caddy MemeQuiz публикует только порт 443 и получает сертификат через TLS-ALPN-01 challenge, которому порт 80 не нужен. Схема осталась со старого сервера, где порт 80 был занят; на новом сервере 80 свободен, так что при желании можно перейти на обычный HTTP-01 с редиректом на https.

- [x] `.env` (`chmod 600`), `SITE_ADDRESS=memequiz.94-141-161-179.sslip.io`.
- [x] `docker compose up -d --build`, в логах Caddy есть `certificate obtained successfully`.
- [x] `https://memequiz.94-141-161-179.sslip.io` открывается с валидным сертификатом.

## Риски / заметки

- `http://` (без https) не отвечает: порт 80 не опубликован. Telegram и ссылки всегда используют https, так что это некритично.
- Если понадобится вернуть MTProto-прокси Amnezia на 443, придётся либо перенести его на другой порт, либо ставить L4-прокси с маршрутизацией по SNI.

- Let's Encrypt ограничивает количество выпусков сертификатов. При экспериментах не удаляйте volume `/data` у Caddy.
- У sslip.io и DuckDNS тоже бывают лимиты и простои. Для «боевого» запуска можно позже купить свой домен.
- Не теряйте JSON-ключ: Google не даёт скачать его повторно, придётся создавать новый.
